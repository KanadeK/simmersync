# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and Semantic
Versioning.

## [0.1.0] - 2026-07-28

### Added

- Deterministic multi-dish backward scheduler.
- Dependency graph and configurable resource capacities.
- Active/passive steps, cross-dish `after`, `serveOffset`, and `maxHold`.
- YAML and JSON validation with stable exit codes and repair hints.
- Terminal, JSON, CSV, ICS, and offline Cook Mode HTML exporters.
- Three sample plans, including an intentional infeasible case.
- Strict TypeScript build, tests, coverage gates, acceptance test, benchmark, CI, release builder,
  SHA-256 manifest, and clean-install release verification.
- English and Simplified Chinese documentation.
