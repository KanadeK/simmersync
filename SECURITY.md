# Security policy

Supported version: `0.1.x`.

Please report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/KanadeK/simmersync/security/advisories/new).
Do not open a public issue before a fix is available.

Include the affected version, minimal local plan, exact command, impact, and reproduction steps.
Never include credentials or unrelated personal data.

See [the security and privacy model](docs/security-and-privacy.md) for the intended trust boundary.
