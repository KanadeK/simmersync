# Roadmap

## v0.2 — integrations

- Import timed Cooklang steps into a draft SimmerSync plan.
- Export Home Assistant-friendly events.
- Add a plan migration command and schema compatibility tests.

## v0.3 — richer constraints

- Optional hard freshness windows.
- Multiple named cooks and task assignment.
- Steps that consume a resource only during setup or teardown.

## Later research

- Compare the deterministic heuristic with an optional exact solver.
- Replan unfinished steps after a real-world delay.
- A browser composer that calls the same tested core rather than duplicating scheduling logic.

Non-goals remain recipe scraping, nutrition advice, accounts, telemetry, and AI-generated cooking
instructions.
